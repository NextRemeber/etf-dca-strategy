## 一、策略框架

**逆向分档定投 + 区块隔离 + 月度分数轮动**。核心思想：
- **增量资金**（工资/现金流）→ 月度定投，按逆向打分分档控制节奏
- **存量资金**（已有积蓄）→ 按 70/30 一次或分批建仓，与定投同池管理
- **月度轮动** → 存量持仓再平衡，纪律性收割相对强弱切换

```
预算结构（月 10000 为例）:
  基本配置 60% = 6000/月（纳指 2000 + 红利低波 2000 + 豆粕 2000）→ 纯定投 1x
  周期卫星 40% = 4000/月（AI 2000 + 黄金 2000）     → S3 分档
```

## 二、组合结构（经验证最优）

| 区块 | 占比 | 标的 | 代码 | 角色 |
|---|---|---|---|---|

| 基本配置 | 60% | 红利低波 | 512890 | A股高股息，压舱石 |

| 周期卫星 | 40% | AI | 159819 | A股科技主题，高弹性 |
| 周期卫星 | 40% | 黄金 | 518880 | 商品避险，与AI相关性最低(0.087) |

- **区块隔离最优**：跨块轮动 4 形态全失败；黄金放周期（Calmar 2.01 vs 1.71）
- **固定池不换标**：机械换标 43%≈随机；池内低相关是收益基础
- **豆粕 2026-08-21 加入基本配置**：12 候选中唯一真低相关（0.104），2022熊市+61.4%对冲，混合场景三窗口 Calmar 全面提升（⚠️ 该组数字为外部 bug 口径，方向三窗口一致可信，绝对值待 backtest_core 复跑），回撤改善；参与轮动反降，故不参与（保险角色 1x 独立持有）。修正后 v3.1 全组合（含豆粕）回测：无闸门 IRR 18.5%/回撤 -7.0%/Calmar 2.64（vs 不含豆粕 20.4%/-8.2%/2.50：豆粕以 ~2pp IRR 换回撤改善）
- **60/40 比例（2026-08-21 修复后引擎重跑确认）**：Calmar 2.82 vs 70/30 的 2.71，两轮实验一致（混合场景 2.10 vs 1.95）；轮动组合测试：双周 2.95 略优/无条件 2.85 略优/调仓50-25 2.87 略优，均在噪声内，维持月度+阈值5+30/15

## 三、定投规则（V0 打分 + S3 分档）

**打分**：V0 = MA60偏离(50) + 60日动量(30) + BOLL位置(20)，0-100，**逆向**（分值越高=越超跌=越值得多投）

**S3 分档**（周期卫星；基本配置为 1x 纯定投）：

| 分值 | 档位 | 倍数 |
|---|---|---|
| ≥90 | 🔥深度低位 | 3x |
| 70-89 | 🟢低位 | 2x |
| 50-69 | ➡️正常 | 1x |
| <50 | 🟡高位/偏高 | **0.25x**（不空仓） |

- 低档 0.25x 全参数寻优确认（0x 断供 Calmar 更高但有纪律风险，不采用）
- 定投频率周/双周/月无显著差异（<1pp），维持月度
- 打分权重 50/30/20 八轮穷举全局最优

## 四、月度轮动规则（存量再平衡）

```
每月首个交易日:
  基本配置: 纳指 vs 红利低波 分差≥5 → 调出低分者 30% 持仓 → 买入高分者
            （豆粕不参与轮动，1x 保险角色独立持有）
  周期卫星: AI vs 黄金 分差≥5 → 调出低分者 15% 持仓 → 买入高分者
  例外: 纳指溢价>8% 时跳过"买入纳指"方向（QDII 套利保护）
  分差<5: 不调仓（方向噪声）
```

- 轮动是核心增益（修正后：不轮动 IRR 14.8% → 18.4%，**+3.6pp**；旧文档 +4pp 为 bug 口径）
- 分差 3/5 等价、10 太严、无条件略差；调仓 50/25 是激进档（IRR 高 2.2pp 但回撤深 1.8pp，不采用）
- 无条件再平衡最优（触发条件损失溢价）；与止盈互斥（叠加 2.55→2.26）

## 六、存量资金处理（混合场景）

- **期初建仓**：按 70/30 一次性买入（基本 35%×2 + 周期 15%×2），或分 3-6 批降低择时风险
- **混合场景验证**（修正后口径）：20 万存量 + 每月 5000 定投 → IRR 18.4%、回撤 -9.6%（介于纯定投与纯存量之间）
- 存量全仓是"资金效率换绝对收益"的权衡，与策略优劣无关
