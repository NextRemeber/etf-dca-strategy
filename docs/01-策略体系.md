## 一、组合结构

### 1.1 区块隔离（70/30）

```
总预算 10,000 元/月
├── 基本配置 70%（7,000 元）—— 慢牛资产，稳定器
│   ├── 纳指ETF (513100)      3,500 元
│   └── 红利低波ETF (512890)   3,500 元
└── 周期卫星 30%（3,000 元）—— 高波动资产，收益引擎
    ├── AI ETF (159819)       1,500 元基础
    └── 黄金ETF (518880)      1,500 元基础
```

**为什么区块隔离不可动**（跨配置层调仓验证，4 形态全部失败）：
- 区块内两只是**同类资产**——分数差反映真实的相对强弱切换，轮动可收割
- 跨区块是**不同类资产**——分数差异主要反映波动率差异（噪声），不是相对强弱
- 全局四标的轮动 2.11 vs 区块内轮动 2.55；跨区块双向调仓回撤恶化 2pp

## 二、三个执行机制

### 2.1 S3 分档定投（周期卫星）

**分数定义**（V0，逆向指标：高分=超跌=值得多投）：

| 子因子 | 公式 | 分档 → 得分 |
|--------|------|------------|
| MA60偏离（50分） | (收盘/MA60−1)×100 | <−15→50 │ −15~−5→40 │ −5~5→25 │ 5~15→10 │ >15→0 |
| 60日动量（30分） | (收盘/60日前−1)×100 | <−20→30 │ −20~−5→20 │ −5~5→12 │ 5~20→5 │ >20→0 |
| BOLL位置（20分） | 价格 vs MA20±2σ | 下轨下→20 │ 下轨~中轨→14 │ 中轨~上轨→8 │ 上轨上→0 |

**投入倍率**：

| 分数 | 倍率 | 说明 |
|------|------|------|
| ≥90 | 3.0x | 黄金坑重仓 |
| ≥70 | 2.0x | 低位加仓 |
| ≥50 | 1.0x | 正常定投 |
| <50 | **0.25x** | 高位减投（全参数寻优确认，非 0.5x） |

**权重 50/30/20 的验证**：轮动框架下重测仍最优；三因子互补（去 BOLL 损失 2.75pp IRR）；权重是平台（均权 2.53 ≈ 50/30/20 的 2.55）；分档边界 ±2pp 平移无尖峰。

### 2.2 分数轮动（再平衡纪律，核心增强）

```
每月初定投后：
  计算区块内两只标的前一日分数
  |分差| < 5  → 不调仓（方向噪声）
  |分差| ≥ 5  → 卖出低分者持仓的 X% → 买入高分者
               基本配置 X=30%，周期卫星 X=15%
例外：纳指溢价>8% 时跳过"买入纳指"方向的调仓
```

**为什么有效（理论）**：再平衡溢价（diversification return，Bernstein & Wilkinson 1997）——两个不同步的同类资产，定期把仓位从涨多的移到跌多的，组合复利收益 > 加权平均收益。分数方向让每次调仓天然"低买高卖"。

**为什么是这些参数（实证）**：
- 无条件最优：任何触发过滤（分差阈值≥8/高位确认/分差比例）都损失溢价——但分差<5 不调省成本不打折（噪声过滤的最优边界）
- 30%/15%：基本配置收益回撤双改善（15-50% 区间平台，30% 中心）；周期卫星 15% 更稳（30% 回撤略升）
- 月度最优：双周/周度无增量（分数是慢变量，20/60日均线，高频=噪声+成本）；季度是灾难（-1.08）
- α 归因：随机方向对照增益 -0.74pp vs 分数方向 +4.15pp，**100% 超随机**——增益来自分数信息而非再平衡动作本身

**诚实边界**：轮动增益月份级不显著（62 次调仓 p=0.128，胜率 55%）——**厚尾期权型收益**（少数大切换月贡献主体），空窗年份可能零增益。

### 2.3 纳指溢价闸门（QDII 套利保护）

```
纳指溢价 = 场内价格 / 基金净值 − 1（raw 价格 ÷ 官方单位净值，2026-08-21 重建口径）
≤8%：场内正常买入（0~5% 区间买入后 60 日 +5.57% 最肥）
>8%：改场外申购（按净值成交）——不是停买！（停买仅 +1.36pp 小增益，改道是主选）
```

**8% 阈值的实证依据**（真实溢价序列重验，2026-08-21）：分档 60 日收益单调递减
（0~5% +5.57% → 5~8% +3.45% → 8~10% -1.12% → 15%+ -1.50%）；IC20=-0.234 短期
负相关（强于旧口径 -0.072）；但 **>8% 整体 +0.61%，8% 非精确转负边界**（旧 -4.10%
为污染数据结论）。真实 >8% 天数：2020 年 108 天 / 2021 年 0 天 / 2025 年 22 天 /
2026 年 50 天（总 8.7%）。闸门机会成本 ~0.4pp IRR（组合回测差距 0.28~0.47pp）。

## 三、明确不做的事（全部有验证依据）

| 不做 | 依据 |
|------|------|
| **无止盈点** | 轮动即渐进式高位减持；止盈与轮动冲突（叠加 2.55→2.26）；单段/两段/分数/趋势止盈全输持有 |
| 不换标 | 机械换标 43%≈随机；当前 4 支是 9880 穷举 + 双周期筛选结果 |
| 不做区块间资金流动 | 跨区块调仓 4 形态全部更差 |
| 不做高频调仓 | 双周/周度无增量 |
| 不预测顶 | 10 个顶部因子双周期验证无一有效；A股顶在统计上不可预测 |
| 不用 bull_align 做自动交易 | 73% 是市场 beta；自动卖出 IRR 砍 85%——只用作人工监控 |

## 五、方法论五原则

1. **双周期验证**：当前周期（2020-2026）+ 前周期结构（2014-2019）都通过才采纳；前周期代理必须用国内资产（纳指代理有幸存者偏差教训）
2. **随机对照**：区分 α 与运气（触发加投 p=0.70、regime p=1.0、轮动 100% 超随机）
3. **预算口径 IRR**：现金流按预算入账而非实际投资额（少投策略会虚高）；二分法求解
4. **参数平台**：最优参数必须邻域稳健（尖峰=过拟合）
5. **纪律型 > 预测型**：A股不可预测，可持续 alpha 只来自纪律（本轮全部验证的核心结论）
