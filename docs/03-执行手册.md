# 03 · 执行手册（每月实操指南）

> 日报每天自动运行并输出全部指令；本手册教你读指令并执行。

## 一、每月初执行流程（10 分钟）

### 第 1 步：看日报"💰 今日定投清单"（周期卫星）

```
例：
  AI    (159819)  74分 🟢低位  2.0x  3000元
  黄金  (518880)  74分 🟢低位  2.0x  3000元
```

→ 按显示金额买入。分数高（超跌）会自动放大（最高 3x），分数低（高位）自动缩到 0.25x（400 元以下照买，不空仓）。

### 第 2 步：看"🏦 基本配置"区块

```
例：
  纳指    0.0x  0元    🚫 溢价+11.2%>8% → 改场外申购 3500 元
  红利低波 1.0x  3500元 🟢 正常场内买入
```

→ **溢价 >8% 时不要在场内买纳指**（实证：此时买入后 60 日平均 -4.1%）——改用场外联接基金申购（按净值成交，溢价归零）。资金不要停（纯停买=踏空）。

### 第 3 步：看"🔄 本月分数调仓指令"

```
例：
  基本配置: 红利低波 45分(高位) → 纳指 51分(低位) | 分差6≥5
           → 调出红利低波持仓的30%买入纳指 ⚠️溢价闸门拦截
  周期卫星: AI 74分 vs 黄金 74分 | 分差0<5 → 本月不调仓
```

→ 按指令执行调仓：
- **"调出 X 持仓的 30%"**：X 的持仓市值 × 30% = 卖出金额，卖出后立即买入对手方
- **分差 <5**：本月不动（方向是噪声）
- **⚠️ 溢价拦截**：买入方向是纳指且溢价>8% 时跳过本次调仓（等下月或等溢价回落）

### 第 4 步：看"🚦 赛道强势度监控"（安全检查，30 秒）

```
正常状态：AI 🟢强势 → 什么都不用做
警惕状态：AI 🔴转弱 且"低位持续"接近 60 日 → 连续60日<0.2 时
         日报会显示"🟠 警惕·纳入替换审视" → 人工评估（不是自动卖）
```

## 三、常见问题

**Q：月中价格大跌，要不要提前买？**
A：不要。月度节奏是验证过的最优（分数是慢变量，盘中/周内波动是噪声）。等下月初。

**Q：分数到 90 了要不要 All in？**
A：不要。3x 封顶是纪律（90 分后可能继续跌，医药熊市分数长期 90+ 的教训）。

**Q：轮动连续几个月方向做反了怎么办？**
A：正常。轮动增益是厚尾分布（多数月份≈0，少数大切换月贡献主体），月份级胜率只有 55%——纪律的价值在长期，不在单月。

**Q：AI 连续大跌（如 -30%），S3 会不断加仓，怕不怕？**
A：要知道边界：V 型反弹会赚回（S3 保险）；L 型阴跌会多亏（放大器，压力测试最差亏 8.8%）。🚦 监控 bull_align 连续 60 日 <0.2 是人工干预线——到那时重新评估 AI 赛道逻辑，而不是机械执行。

**Q：纳指溢价一直不回落怎么办？**
A：一直走场外申购即可（按净值成交无损失）；溢价回落 <8% 后恢复场内。

**Q：月预算想改（比如 3000 → 5000）？**
A：`--monthly-budget` 参数改周期卫星预算，基本配置自动按 7/3 比例放大。

## 四、纪律红线（违背 = 体系失效）

1. ❌ 不因"感觉要涨/跌"改变档位——只认分数
2. ❌ 不因"涨太多"卖出——轮动会自动处理
3. ❌ 不跳过调仓指令（分差≥5 就执行，哪怕"感觉方向不对"）
4. ❌ 不在溢价 >8% 时场内买纳指
5. ❌ 不换标（除非年度人工审视 + 🚦 警惕区同时触发）
6. ❌ 不因单月轮动亏损放弃轮动（厚尾特性）

## 五、年度审视（每年一次，约 1 小时）

1. **看 🚦 监控**：四只标的的 bull_align 是否有连续 60 日 <0.2（警惕区）→ 评估该标的是否仍是当期强势赛道
2. **看 🔁 切换参考**：全池当前强势排序（仅参考，机械换标已证无效）
3. **看组合相关性**：四只两两相关是否仍 <0.75（结构漂移检查）
4. **回顾执行纪律**：过去 12 个月是否有违背红线的操作
