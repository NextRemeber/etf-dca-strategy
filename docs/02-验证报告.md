## 阶段八：双重 Grill-me 拷打

**第一轮（参数层）**：日报/单日版/回测引擎分数 0 偏差；权重轮动框架重验仍最优；边界 ±2pp 稳健；黄金慢熊无接飞刀（3x 触发 0 次）；成本 5 倍增益仅降 0.4pp。

**第二轮（设计层，2 项推翻性发现）**：
- 轮动增益月份级不显著（p=0.128）→ 厚尾期权型，空窗年零增益
- **S3+轮动对 L 型崩盘是放大器**（AI 复制医药崩盘：亏 8.8% vs 等权赚 1.8%）→ V 型保险/L 型放大，🚦 监控升级为必须

**过程 bug 教训**（引擎防线）：
- `fillna(0)` 吞 NAV（数据截止日不同）→ 统一区间 + ffill
- 牛顿法 IRR 发散 → 二分法
- 少投策略 IRR 虚高 → 预算口径现金流
- 弹药池注入未计现金流 → t=0 计入
- 高频方案现金入账频率污染 → 入账与调仓独立
- 跨区块调仓绕过 cash 转账 → 单一记账通道

### 溢价闸门的新认知（2026-08-21，重要）

本窗口（2020-2026）**无闸门 IRR 反而最高**（18.5% vs 15.6~16.9%）：2025 年纳指溢价
长期 10-30% 且**未回落**，无闸门回测按含溢价市价买入并按含溢价市价估值，账面占优；
闸门策略（场外按净值成交）永远不捕获溢价。这**不推翻闸门**——闸门保护的是"溢价
崩塌"情景（阶段六实证：>8% 买入后 60 日 -4.1%），本窗口恰好没发生崩塌。定性：
闸门=用 1.5~2.9pp 本窗口账面收益换崩塌保护 + 估值纪律，双界区间即真实效果范围。
