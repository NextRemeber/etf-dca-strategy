# ETF 策略验证协议

> 任何策略结论（含"某方案更优/某因子有效"）必须通过本协议，否则不落地。

## 一、稳健性四件套（缺一不可）

1. **三窗口**：全窗口 + 前段 + 后段分段验证，全部优于基线才成立
2. **前周期样本外**：2014-2019 作为前周期验证（国内代理规避幸存者偏差）
   - 数据不足的标的不参与前周期（如 AI/红利低波 2019 后才上市），用有数据的标的部分验证
3. **随机对照**：新机制 vs 随机化基线（如触发加投 p=0.70、换标 43%≈随机、配对轮动 88%<95%）
   - 随机化打不过 = 无 alpha，结论作废
4. **参数灵敏度**：关键参数邻域扫描（分档边界 ±2pp 平移、低档倍数 0.25/0.5/0.75 单调性）
   - 单点最优而邻域崩塌 = 过拟合，不可落地

## 二、防锚定检查（结论交叉验证）

1. 新结论必须与既有验证结论对照（见 `strategy-conclusions.md`），冲突时先溯源旧结论的验证范围
2. **泛化边界**：旧结论只在其验证过的机制/标的上成立
   - 历史教训："BOLL 调节在慢牛资产无效"被错误泛化为"慢牛资产所有调节无效"→ 漏掉 S3 分档（实际 Calmar 2.89 vs 0.70）
3. 反直觉结果先查引擎 bug，再信结论（免费印钱 bug 曾让分档 IRR 虚高 5.51pp）
4. **现金池口径必须标注**：独立现金池（块预算隔离）vs 共享现金池（真实账户，钱互通）结论可能相反
   - 历史教训（2026-08-20）："基本配置 S3 分档 Calmar 4.26"是独立池口径；共享池口径下全分档+轮动仅 2.60 ≈ 现状 2.56，且 IRR 低 3.4pp——分档省下的钱在共享池被其他块加仓消耗，防御效果稀释
   - 组合级模拟一律用共享现金池（贴近真实账户）；独立池结果必须标注假设

## 三、结论输出格式

```
结论：<一句话>
机制：<为什么有效>
证据：<三窗口 + 前周期 + 随机对照 + 灵敏度数据>
边界：<不适用的场景/标的/窗口>
```
