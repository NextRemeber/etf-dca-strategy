# ETF 回测引擎硬性口径（权威源）

> 所有策略验证脚本必须遵守。违背后结论作废。

## 一、现金与交易口径（防"免费印钱"）

1. **现金储备制**：月初预算入账现金池，投资时 `cash -= amt`（**mult>1 时尤其必须扣**）
   - 历史 bug：`simulate_graded` 中 3x/2x 加仓 shares 增加但 cash 不扣 → 低位多投的钱凭空出现 → **IRR 平均虚高 5.51pp**（新能源 +7.7pp、地产 +10.6pp 最重）
2. **不透支**：`amt = min(monthly * mult, max(cash, 0))`——低位 3x 必须靠前期积累
3. **现金计息**：未投部分按货基 2% 年化计息（`cash *= (1 + CASH_RATE/252)`）
4. **成本**：买入按 0.15% 扣费（`shares += amt * (1 - COST) / p`）

## 二、IRR 计算（防发散与口径欺骗）

1. **牛顿迭代在亏损组合发散** → 一律用**二分法**，区间 `[-0.99, 10.0]`，80 次迭代
2. **IRR 口径会骗人**：少投（0.25x 减投月）会让 IRR 虚高，因为分母小
   - 判据：**资产口径（总终值/总投入）与 IRR 双看**；两者矛盾时以资产口径为主
   - 历史教训："分档 IRR +18.29% 高是因只投 70% 预算"——纯定投 90,051 vs 分档 89,187 实际打平
3. **现金入账必须与调仓/旋转频率独立**：cash 注入固定每月 1 次，轮动/加投频率另算
   - 历史 bug：高频旋转（每周/双周）在 is_first 标记同时入资 → IRR 虚高 +73%

## 三、数据与未来函数

1. **前一日打分**：`scores.shift(1)` 后才可用于当日执行（防未来函数）
2. **买卖必须按当日价格成交**（份额×当日价），**禁止"昨日净值×成本"虚拟成交**：
   - 历史 bug（2026-08-20）：`nav *= (1-COST)` 净值复利法在"先止盈/切换、后更新净值"顺序下，止盈日未计入当日回撤下跌 → 等效以昨日价卖出今天的下跌 → 179 次交易收益虚高 20 倍（2688%→真实 118%）
   - 判据：任何持仓变动日，成交金额必须用**当日价格**；净值复利写法（nav×p/entry）只允许在无交易的日子使用
3. **fillna(0) 吞掉 NAV**：不同起始日 DataFrame 组合时 0 填充 → NAV 跌到 0
   - 修正：`concat + ffill` 统一索引；价格查找用统一索引 `prices[c]`，**禁止** `dict.get(dt, 0)` 兜底
4. **预热期**：打分需 60 日历史预热，`bull_align` 需 300+ 日数据；数据不足的标的直接跳过而非默认值
5. **单位检查**：阈值类参数确认单位（历史 bug：take_profit 阈值写 15 实际应为 0.15 的百分比口径）

## 四、输出与报告

1. 每次验证必须输出：总投入 / 总终值 / IRR / 最大回撤 / Calmar
2. 组合级对比必须三窗口：全窗口 + 前段 + 后段（防止单窗口偶然）
3. 关键结论附机制解释——无机制解释的结果视为可疑（可能是过拟合或 bug）

## 五、引擎发布前强制三查（2026-08-20 审计沉淀）

| 检查 | 方法 | 判据 |
|------|------|------|
| ① 成交价基准 | 重放模拟抽取全部/抽样交易，比对成交价 vs 当日价格 | 逐笔一致；**禁止昨日净值×成本虚拟成交**（未来函数，v2 动量引擎因此淘汰，收益虚报 20 倍） |
| ② 未来函数 | 抽样 10+ 个交易日，验证引擎使用的分数 = 前日分数（shift1 后） | 全部一致 |
| ③ 现金恒等式 | 逐日：入账 - 买入 + 卖出 + 货基息 = 期末现金；现金永不为负 | 恒等式误差≈0，0 透支 |
